# Form Builder — сервис конструктора форм отклика

Менеджер сам собирает форму отклика на стажировку или мероприятие, публикует её по уникальной ссылке и смотрит ответы студентов. Студент переходит по ссылке и заполняет форму.

## Запуск

```bash
npm install
npm start
```

После запуска:

- **Админка:** http://localhost:3000/admin
- **Порт** настраивается через переменную окружения `PORT`: `PORT=4000 npm start`

Внешних сервисов, API-ключей и отдельно устанавливаемых СУБД не требуется — данные хранятся в файле `data/db.json` (создаётся автоматически при первом запуске, вместе с демонстрационными данными).

## Возможности

**Менеджер (админка `/admin`, без авторизации):**
- создаёт форму, добавляет вопросы восьми типов: короткий ответ, развёрнутый ответ, email, число, дата, выпадающий список, один из списка, несколько из списка;
- помечает вопросы обязательными, добавляет подсказки, меняет порядок вопросов;
- публикует форму — получает уникальную ссылку вида `http://localhost:3000/f/<slug>`, кнопку копирования; может снять форму с публикации (черновик по этой ссылке становится недоступен);
- просматривает ответы таблицей и выгружает их в CSV (корректно открывается в Excel, включая кириллицу);
- видит **воронку конверсии**: просмотры → начали заполнять → отправили, а также таблицу «где студенты бросают форму» — по какому вопросу остановились те, кто не нажал «Отправить».

**Студент (публичная страница `/f/<slug>`):**
- заполняет форму по ссылке: подсказки, обязательные вопросы, проверка полей до отправки;
- видит сообщение об успехе после отправки;
- при ошибке валидации на сервере — подсвечивает конкретные проблемные поля.

## Аналитика конверсии

Сервис фиксирует события `view` (просмотр), `start` (первое взаимодействие с полем), `abandon` (вкладка закрыта до отправки, с последним полем) и `submit`. На странице ответов это сводится в воронку и подсказку «больше всего студентов останавливаются на вопросе …» — прямой ответ на проблему низкой конверсии из ТЗ. Предпросмотр из админки (`?preview=1`) в статистику не попадает.

## Структура проекта

```
server/          Express-приложение: маршруты, хранилище, валидация, аналитика
public/admin/    три страницы админки: список форм, билдер, ответы
public/form/     публичная страница формы (рендер из JSON-схемы)
data/db.json     хранилище данных (создаётся автоматически)
```

## Стек

Node.js ≥ 20, Express, хранилище — JSON-файл с атомарной записью. Фронтенд — без сборки: ванильный HTML/CSS/JS.
